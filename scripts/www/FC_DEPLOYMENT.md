# 阿里云函数计算 (FC) 部署指南

## 文件结构说明

为阿里云函数计算 Custom Runtime 环境准备的文件：

```
├── bootstrap           # Custom Runtime 入口脚本
├── server.js          # Node.js 服务器入口文件
├── package.json       # 包含生产环境依赖和脚本
├── dist/              # 构建后的静态文件（npm run build 生成）
└── FC_DEPLOYMENT.md   # 本部署文档
```

## Custom Runtime 配置

### bootstrap 文件说明
- **作用**: 阿里云函数计算的入口点
- **权限**: 需要设置为可执行 `chmod +x bootstrap`
- **端口**: 服务需运行在 9000 端口

### 部署步骤

1. **本地构建**
   ```bash
   npm run build
   ```

2. **阿里云控制台配置**
   - 选择 Custom Runtime
   - 函数入口: `bootstrap`
   - 运行环境: Node.js 18+

3. **上传方式**
   - **方式一**: 直接上传 zip 包（包含所有文件）
   - **方式二**: 通过 OSS 上传

## 环境变量配置

在阿里云函数计算控制台设置环境变量：
- `NODE_ENV`: production
- 其他环境变量按需配置

## 测试部署

本地测试生产环境构建：
```bash
# 构建项目
npm run build

# 启动生产服务器
npm start
```

访问: http://localhost:9000

## 注意事项

1. **端口要求**: 必须监听 9000 端口
2. **健康检查**: 阿里云会访问 `/` 路径进行健康检查
3. **超时设置**: 建议设置合理的执行超时时间
4. **内存配置**: 根据项目需求配置合适的内存大小

## 故障排除

### 常见问题
1. **端口占用**: 确保只有 9000 端口被监听
2. **权限问题**: bootstrap 文件需有执行权限
3. **构建失败**: 检查 package.json 依赖和构建脚本
