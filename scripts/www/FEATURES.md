# MingHui Real Estate Pro - 全量功能特性汇总 (2025.03)

明惠 Pro 是一款专为独立经纪人和精品门店设计的**隐私驱动型**地产数字化系统。

## 一、 获客与数字营销 (Lead Gen & Marketing)
*   **H5 智能分发引擎**:
    - **一键云端发布**: 房源详情秒变高颜值 H5 页面。
    - **流量溯源**: 每个分享链接自带经纪人 ID 埋点，实时监控访客路径。
    - **即时预约提醒**: 访客在 H5 填写的预约信息通过 API 中转，实时推送到工作台。
*   **跨平台房源一键“洗稿” (AI Rewrite)**:
    - **内容去敏**: 自动识别并剔除竞品平台标签、原经纪人联系方式及敏感水印信息。
    - **二次创作矩阵**: 针对同一套房源，一键生成“专业公文、温情小红书、紧急促销、朋友圈短文”四种风格。
    - **获客逻辑**: 极速铺设全网内容，通过差异化人设文案提升点击率。
*   **AI 内容矩阵工坊**:
    - **短视频脚本生成**: 基于房源动线，自动生成包含镜头语言、口播、BGM 建议的脚本。
    - **营销图谱**: 自动提炼房源卖点，生成适合不同平台的标签系统。
*   **数字海报实验室**:
    - **Canvas 实时渲染**: 无需后台，浏览器端直接生成 300DPI 印刷级海报。
    - **动态二维码**: 自动嵌入带获客追踪参数的房源专属二维码。

## 二、 核心数据架构 (Storage Architecture)
*   **物理级数据安全**: 
    - **FS Access API**: 行业首创，网页版直接读写电脑本地 JSON 文件夹，服务器不留存任何房源客源数据。
*   **云端快照桥接 (Snapshot Bridge)**:
    - 解决移动端 Web 无法写磁盘的痛点。
    - 支持“PC 端一键推送 -> 云端加密暂存 -> 手机端一键拉取覆盖”。
*   **智能数据自愈**: 基于 Zod 协议的 Schema 自动补全，防止由于版本更迭或手动修改 JSON 导致的系统故障。

## 三、 房产业务管理 (CRM & Operations)
*   **房源 360° 管理**:
    - **水印保护系统**: 上传照片自动叠加“姓名+电话”防盗水印，保护核心资产。
*   **客源画像系统**:
    - **A/B/C 等级自动评估**: 基于资金、动机、配合度三个维度的智能评分。
*   **虚拟钥匙挂板**:
    - **实物感知**: 模拟实体钥匙柜，红色/绿色代表借出/在库。

## 四、 智能辅助 (AI Agent)
*   **本地 RAG 助手**: 基于向量检索实现的本地知识库，AI 能够通过“阅读”你的房源数据来回答问题。
*   **业务自动化命令**: “帮我把碧桂园的价格改为 300 万” -> 自动执行。
